## Overview

Your GitHub profile now displays the highest tier you've earned for achievements with multiple levels. Previously, profiles could display the first tier earned, even after you had progressed to higher tiers. This change ensures that users can see their highest achievements right away, making it easier to showcase their most impressive work and accomplishments.

Imagine you're a software engineer working on a project. You've completed several milestones, each with a different level of achievement. Up until now, the profile might only show the first milestone you achieved, even after you've surpassed it. This update allows users to see the highest achievement level, showcasing their full range of accomplishments at a glance.
